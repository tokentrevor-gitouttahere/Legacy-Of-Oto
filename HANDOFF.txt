WHAT WAS BUILT (details: docs/STATUS.md and the build status in docs/MECHANICS_REFERENCE.md)
  Combat:
    - Floating damage numbers.
    - A held heavy strike: hold Z, release once it is ready.
    - Ki techniques switched with Q: Charged Orb and Ki Blast.
  Ki charge:
    - Five tiers from Basic Charge to Perfect Charge, each with its own delay and rate.
    - The prologue has Perfect; the throw resets it to Basic.
    - Goku's spar teaches Steady, and Roshi's optional lesson teaches Focused.
  Growth:
    - Level cap 100, and a stat cap of 255 on what points and capsules add.
    - Capsules worth +1, +3 and +5, some placed in the world.
  Drops: food (haunch, rice ball), ki motes and capsules.
  Senzu beans are carried and eaten from the Journal page (Yajirobe gives one at a time).
  Enemies:
    - Behaviours: chase, charger, shooter and pack.
    - Tiers 1-4 that scale stats and tint the model.
    - They collide with walls, wander until Oto comes within 12 m, and give up past 24 m.
  Beasts: six procedural animals (wolf, boar, raptor, scorpion, crab, pterodactyl) in
    scripts/characters/beast.gd. They are in the gallery's "beasts" page.
    - Mt. Paozu: wolves, boars and raptors.
    - Korin's Holy Land: tier-2 wolves, boars and raptors.
    - The Wasteland: scorpions and pterodactyls (the Saibamen now hunt as a pack).
    - Kame House: crabs.
  Fixtures (scripts/world/fixture.gd): level gates, memory gates, key doors, floor switches,
    bridges, breakable rocks, save lanterns, Chi-Chi's leftovers pot and fishing jetties.
    - Every outdoor location has a save lantern.
    - The Wasteland has a level-5 gate with capsules behind it.
    - levels/dev_fixtures.json has one of each fixture.
  Saving: save at lanterns, Continue on the title, and a fall reloads the last save.
  Quests: a journal ("A Place to Eat" at Paozu, Roshi's lesson).
  The Menu: 8 dishes from 7 cooks, with milestones that raise max HP or give stat points.
  Scan (T): ki sense shows a power band; the Scouter key item adds exact numbers. Nothing in
    the story gives the Scouter yet.
  Bosses: scripts/boss_kit.gd adds phases, ki absorption and drain. The prologue boss runs on it.
  Tests: python tools/run.py test runs 52 headless rule checks, all passing.
  Fixes made along the way:
    - The title layout collapsed in screenshots.
    - HUD text was unreadable on bright ground.
    - The Test Arena stayed black when entered from the title.

LOCKED DECISIONS (the owner, 2026-10-28)
  - Transform gauge: none. Shadow forms drain ki per second.
  - Stat growth: 3 points per level, placed by the player.
  - Gates: level gates plus memory gates (a Shadow form or memory flag). A memory gate must
    never open before its rung of the memory ladder.
  - Scan: ki-sense first; a scouter later adds exact numbers.
  - Caps: levels at 100; each stat at 255.
  - Death: reload the last save (the old respawn only applies when there is no save).
  - Consumables are meals, approved: haunch, rice ball, ki mote, Chi-Chi's leftovers, fresh
    fish, senzu bean, and the Menu as the big collectible.
  - Ki charge: stand still to charge.
    - Tiers and rates: Basic 1.0 s / 8%, Steady 0.7 s / 12%, Focused 0.45 s / 18%,
      Deep 0.25 s / 25%, Perfect 0.1 s / 35% (delay before ki rises, then share of max ki
      per second).
    - Teachers: Goku's first spar teaches Steady; the gravity machine on the ship to Namek
      teaches Focused, or Roshi's optional side lesson at Kame House teaches it earlier;
      Kami and Mr. Popo's white room teaches Deep; Whis teaches Perfect.
  - Buttons: ours to choose. LoG II's layout doesn't matter.

OWNER PREFERENCES AND STANDING RULES
  - Stay faithful to the story bible.
    - Comedy is food, never pain.
    - Never undercut a real beat.
    - Shadow forms are void, hush and stillness; never gold, fire or lightning.
    - Never skip a rung of the memory ladder.
  - Borrow Legacy of Goku II's style, not the game itself: no copied maps, quests, dialogue or
    exact numbers, and no ROM-derived code.
  - The owner likes big autonomous passes. Check with tools/run.py screenshots and tests, and
    list open decisions at the end instead of stopping to ask (they may be away).
  - New dialogue that Claude writes gets listed for the owner's review (below).

HOW TO RUN, TEST AND SHIP
  Godot 4.7.2 (console exe): C:\Users\Owner\Downloads\Godot_v4.7.2-stable_win64.exe\...  (tools/run.py finds it)
  python tools/run.py import          re-import, report script errors (needed after adding a class_name)
  python tools/run.py test            headless rule checks; keep them passing, add one per new rule
  python tools/run.py shot <scene|level:id> [--args="..."]   screenshot to tools/out/
  python tools/run.py levels          validate levels/*.json
  python tools/make_locations.py      rebuild the canonical levels. It reproduces the files exactly,
                                      so add content here, not by hand-editing JSON
  python tools/publish_web.py         export the "Web" preset and force-push it to gh-pages;
                                      Pages updates in about a minute
  Web templates: only the web_*.zip templates are installed, in
    %APPDATA%\Godot\export_templates\4.7.2.stable. They came from the official
    Godot_v4.7.2-stable_export_templates.tpz (1.28 GB); a copy of that archive is still in
    this session's scratchpad, which is temporary.
  Web build: Compatibility renderer (WebGL 2), single-threaded so GitHub Pages needs no special
    headers; levels/*.json are bundled through the preset's include filter. Saves go to browser
    storage. Lighting is a little flatter than on desktop.
  git: the local repo is set to the GitHub no-reply address
    (346683029+tokentrevor-gitouttahere@users.noreply.github.com), which keeps the personal
    email out of the public history. Commits end with the Claude co-author line.
  Not played by hand yet: a fall that reloads a save inside a real location, Roshi's lesson on
