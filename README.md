# Legacy of Oto

A top-down 3D action RPG fan game in the style of *Dragon Ball Z: The Legacy of Goku*, built in
Godot 4.7. It retells Dragon Ball Z through Oto, an amnesiac first-age Saiyan queen thrown
through time.

**Play in your browser:** https://tokentrevor-gitouttahere.github.io/Legacy-Of-Oto/

## Controls

| Action | Keys |
| --- | --- |
| Move (double-tap to run) | Arrows / WASD |
| Attack (hold for a heavy strike) | Z / J |
| Ki technique (hold to charge or stream) | X / K |
| Switch ki technique | Q |
| Guard / barrier | C / L, then C + X |
| Charge ki (stand still) | V |
| Shadow form up / down | F / G |
| Talk, rest, fish | E |
| Scan (ki sense) | T |
| World map | Tab |
| Menu | Enter / Esc |

## Building

Open the folder in Godot 4.7.2 and press F5. For developers, `CLAUDE.md` and `docs/` describe
the layout, tools and level format. `python tools/run.py test` runs the rule checks, and
`python tools/publish_web.py` deploys the web build.
